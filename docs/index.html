Why it exists

In 6-channel USB Audio mode (Modded-Cycles / ms-multi-output), the Model:Cycles taps each voice pre-mixer. Turning VOLUME+DIST down to 0 removes overdrive, but the dry stem never drops to silence. ModelCycles 6CH fixes this over the same USB cable.

CC 7 • VOLUME + DIST

True Hardware Taper

0–64 smoothly attenuates from complete silence (-∞ dB) to 0 dB unity. 64–127 stays locked at 0 dB so the hardware overdrive passes through without double-boosting.

CC 94 / CC 10 / CC 95

Mute, Pan & Track Level

Restores click-free track Mute (CC 94), converts your mono stems to stereo with hardware Pan (CC 10), and optionally listens to LEVEL/DATA (CC 95).

ZERO ROUTING

Direct USB MIDI or DAW MIDI

Select Model:Cycles directly in the plugin header so all 6 instances share one MIDI port with zero DAW routing — or use DAW MIDI mode to record automation.

Installation & Setup

Takes less than two minutes. Copy the plugin to your system folder, enable MIDI CC output on your Model:Cycles, and drop one instance per track.

  1. 1Unzip ModelCycles-6CH-macOS-Universal.zip.
  2. 2Copy ModelCycles 6CH.vst3 into /Library/Audio/Plug-Ins/VST3/ and/or ModelCycles 6CH.component into /Library/Audio/Plug-Ins/Components/.
  3. 3macOS Gatekeeper (unsigned open-source plugin): open Terminal once and run the command below to allow macOS to load the plugin, then restart/rescan your DAW.
xattr -cr "/Library/Audio/Plug-Ins/VST3/ModelCycles 6CH.vst3"
xattr -cr "/Library/Audio/Plug-Ins/Components/ModelCycles 6CH.component"
  1. 1Unzip ModelCycles-6CH-Windows-x64.zip.
  2. 2Copy the entire ModelCycles 6CH.vst3 folder into C:\Program Files\Common Files\VST3\.
  3. 3Restart or rescan VST3 plugins in your DAW.
STEP A

On your Model:Cycles

  1. 1SETTINGS → MIDI → PORTS: set OUT TO to USB (or M+U).
  2. 2SETTINGS → MIDI → FILTER: set ENCS to I+E.
  3. 3SETTINGS → MIDI → OUT CHAN: set T1–T6 to channels 1–6.
  4. 4For each track T1–T6, press FUNC + TRACK and enable MOUT (saved per pattern).
STEP B

In your DAW

  1. 1Create 6 audio tracks receiving Input 1 through Input 6 from the Model:Cycles.
  2. 2Insert ModelCycles 6CH as the first FX on each track.
  3. 3Click T1 through T6 respectively on each instance.
  4. 4Pick Direct: Elektron Model:Cycles in the top-right dropdown for zero-routing setup, or leave DAW MIDI if routing MIDI inside your DAW.
Hardware limitation note: The Model:Cycles transmits MIDI CC only for physical knob turns and track mutes. Parameter Locks (P-Locks) and LFOs assigned to DIST do not send MIDI CC out. On Windows, if you use Direct MIDI mode, disable the Model:Cycles MIDI input in your DAW preferences so the plugin can open the port exclusively.
